# 유사 서비스와 사용자 리뷰 조사

- 조사일: 2026-11-05 ~ 2026-11-06
- 목적: Betro MVP의 포지셔닝과 차별점을 정하기 위한 근거. 결론은 [`2026-11-05-mvp-design.md`](../superpowers/specs/2026-11-05-mvp-design.md) 1장 "포지셔닝"과 11장에 반영했습니다.
- 방법
  - 웹 리서치: 출처 19곳에서 주장 89개를 뽑았고, 그중 25개를 3명이 교차 검증해 23개를 확인하고 2개를 기각했습니다.
  - Google Play 리뷰: 앱 12개에서 약 10,700개를 수집했습니다. 최신순과 관련도순을 합쳤습니다. 카카오맵·네이버지도·티맵은 대중교통 관련 리뷰만 걸렀습니다.
  - App Store: 공개 리뷰 RSS가 비어 있어서, 앱 페이지에 노출된 리뷰를 앱마다 10개씩만 봤습니다.
  - 커뮤니티: 클리앙, 에펨코리아, 루리웹, Reddit 미러, Hacker News를 봤습니다. X, 더쿠, 디시, 네이버 카페, 뉴스 댓글은 접근하지 못했습니다.
- 한계
  - 리뷰 주제 비율은 키워드 분류로 낸 대략값입니다. 주요 주제는 공감 수가 많은 원문을 읽어 확인했습니다.
  - "기능이 없다"는 판단 상당수는 스토어 설명에 언급이 없다는 데 기댄 것입니다. 실제 기기로 확인하지는 않았습니다.
  - 카카오와 네이버는 대중교통 기능을 매달 바꾸므로, 이 문서를 인용하기 전에 다시 확인해야 합니다.

| 서비스 | 핵심 기능 | 잠금화면 Live Activity | 시작 방식 | 출퇴근 기능 |
|---|---|---|---|---|
| 네이버지도 | 실시간 열차 위치(2024~), 승하차 알림·음성 안내, 대중교통 위젯 | 있음 (2024-04~) | 목적지 설정 후 "안내시작" | 같은 시간대 자주 가는 경로 제안(사용자 댓글 기준, 방식 미확인), 경로 즐겨찾기 |
| 카카오맵 | 길안내, 승하차 알림, 초정밀 지하철(지도 레일 위 열차), 버스 도착 알림 | 있음. 버스 도착 알림, 대중교통 길안내(2026-10, v6.30.0) | 길안내 시작 또는 도착 알림 설정 | 홈 탭 출퇴근 이동 카드(2025-06, v6.3.0). 집·회사·학교 등록 후 "안내시작" |

| 또타지하철 (서울교통공사) | 노선별 열차 위치, 칸별 혼잡도(일부 노선 실측), 민원 신고 | 확인 안 됨 | — | — |
| 지하철 종결자 | 도착 정보, 혼잡도, 지연 소식, 하차 알람, 카톡 공유 | 확인 안 됨 | — | 경로 즐겨찾기 요청이 많음 |
| 이번정거장 | 지하철 하차 알림, 열차 위치, 출퇴근길 등록, 퇴근 알림. **지하철만** | 다이내믹 아일랜드에 남은 정거장 | 앱에서 시작. 퇴근 알림은 시작하라고 알려 주는 것으로 보임(추정) | 있음. **연 약 2만 원 구독** |
| Transit (해외) | GO 모드, 출발 리마인더, 실시간과 시간표 아이콘 구분 | 있음 (2022~). Android Live Notifications | GO를 직접 시작. 60분 이내 출발만 | 즐겨찾기, 집·회사 |
| Citymapper (해외) | 경로 탐색, 잠금화면 내비 | 있음(회사 공지) | 수동 | 저장한 장소 |
| Moovit (해외) | 경로 탐색. 유료 Moovit+(경로 비교, 지도 위 차량 위치, 도착 10분 전 알림) | — | — | — |

**결론**
- 실시간 지도, 잠금화면 Live Activity, 출퇴근 장소 등록은 이미 있는 기능입니다. 차별점이 되지 않습니다.
- 확인된 경쟁 서비스 가운데 다음 두 가지를 하는 곳은 없었습니다.
  - 정해 둔 요일·시각에 Live Activity가 자동으로 시작되는 것
  - 사용자가 등록한 대안 경로를 실시간으로 비교해 제안하는 것
- 다만 카카오와 네이버는 출퇴근 등록과 Live Activity를 모두 갖고 있어서 빠르게 따라올 수 있습니다.

**정정**: 첫 웹 리서치는 "네이버지도에 대중교통 Live Activity가 없다"고 결론 냈지만 틀렸습니다. 클리앙 글 ["드디어 네이버맵 실시간 지도 볼 수 있네요 (Dynamic Island)"](https://www.clien.net/service/board/cm_iphonien/18685987)(2024-04-03)에서 확인했습니다. 스토어 설명에 문구가 없다는 이유로 기능이 없다고 판단하면 안 됩니다.

### 2.2 Betro에 중요한 리뷰 근거

- **출퇴근 자동화를 사용자가 직접 요청함**
  - 네이버지도(2026-10-20): "매일 동일한 시간 동일 코스 출퇴근 할때 사전 예약으로 동일 시간때 자동 안내되도록"
  - 지하철 종결자(공감 307): "경로 즐겨찾기 기능좀 만들어주세요. 출퇴근같은 매번 쓰던경로 시간표보려고 검색할때마다 직접짜는거 너무 불편합니다"
  - 카카오맵(App Store, 2025-12): "경로 고정 기능 … 매번 다시 검색하는 거 너무 번거롭습니다"
- **정류장으로 가는 동안 앱 밖에서 남은 시간을 보고 싶어 함**
  - 카카오맵이 2026-10 Android 알림에서 도착 예정 시간을 빼자 반발이 나왔습니다.
    - "지하철/버스가 몇 분 남았는지는 역/정류장에 도착해서보다도 역/정류장으로 가는 중에 궁금한 정보입니다"
    - "그거때메 ㄴㅇㅂ 안쓰고 카맵 쓰는건데"
  - 카카오버스(2025-04): "보통 버스 도착 10분 전에 맞춰서 집에서 나가는데 … 남은 시간을 확인할 수 없어요"
- **Live Activity가 앱을 바꾸는 이유가 됨**
  - 네이버가 Live Activity를 내자 나온 반응입니다.
    - "이로써 카카오맵 완전 탈피입니다"(클리앙, 2024-04)
    - "아이폰 라이브 액티비티 지원이 … 걍 카카오맵 쓸 이유가 없어지더라"(에펨, 2024-11)
- **저장해 둔 경로가 사용자를 묶어 둠**
  - "경로 즐찾해놓은거 때문에 썼는데"(클리앙, 2026-08)
- **정확도 불신**
  - "5분 남았던 게 갑자기 13분"(카카오맵)
  - "3분남았다떴는데 내 눈앞에있어"(카카오버스, 2026-10)
  - "버스가 온다고 되어있는데 아예 오질 않아서"(네이버)
  - "임시공휴일인데 평일로 적용"(카카오지하철, 2025-06)
  - 같은 문제가 해외에도 있습니다. "Ghost bus"(Transit, Reddit)
  - 오하이오 주립대 연구(Liu & Miller, 2020)에 따르면, 실시간 예측 시각에 딱 맞춰 정류장에 간 사람은 약 75%가 버스를 놓쳤습니다.
- **하차 알림이 늦게 옴**
  - "버스 하차하고 3분쯤 지났을 때 알림"(갤럭시 S25, 에펨)
  - Android 절전(도즈) 모드가 원인으로 추정됩니다.
- **개편과 광고로 사용자가 떠남**
  - 카카오버스 2025-04 개편 리뷰(공감 1,266): "카카오버스의 장점은 정류장에서 빠르게 켜서 분 단위…"
  - Moovit: "ads appear when you really need to see the info"
  - Subway Korea: 출근길에 종료 팝업 광고, 알리익스프레스로 자동 이동
  - 반면 이번정거장은 "군더더기가 없다"는 칭찬을 받습니다.

## 3. 수익 모델 근거

- **구독은 출퇴근 특화 앱에서도 성립합니다**
  - 이번정거장: 연 약 2만 원. "1년에 2만원 충분한 가치가 있습니다"(App Store, 2026-08)
  - Transit Royale: 연 약 $25. 핵심 기능은 무료로 유지합니다([Royale FAQ](https://help.transitapp.com/article/362-royale-faq)).
  - Moovit+: 2023-08 출시([보도자료](https://moovit.com/press-releases/moovit-plus-launch-business-strategy/)).
- **무료였던 기능을 유료로 막으면 반발합니다**
  - Citymapper 2022: 음성 안내와 버스 경로 일부를 유료화했습니다.
  - Transit: 무료는 근처 2~3개 노선만 보입니다.
- **잠금화면에는 광고를 넣을 수 없습니다**
  - Apple HIG는 Live Activity로 광고나 프로모션을 보여 주는 것을 금지합니다. 2022년의 "avoid"가 지금은 "don't"로 바뀌었습니다.
  - 2026-01 Duolingo가 다이내믹 아일랜드 광고로 위반 논란을 빚었습니다([MacRumors](https://www.macrumors.com/2026/01/02/duolingo-dynamic-island-ad/)).
  - Google Play는 시스템 알림을 앱 핵심 기능이 아닌 홍보에 쓰는 것을 금지합니다([정책](https://support.google.com/googleplay/android-developer/answer/9969861)).
